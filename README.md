# Yet another calculator (yac)

`yac` is a simple CLI calculator with a parser, built with C++ and CMake as the build system.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Parentheses (`()`) for expression grouping

## How to build

Clone this repository and run the following commands:

```bash
cmake -B build
cmake --build build
```
